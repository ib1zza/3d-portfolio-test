# MATTER — портфолио Михаила Пшеничного

Живой WebGL-сайт на React Three Fiber: один непрерывный 3D-мир, кастомный скролл,
переходы между страницами через порталы, шейдеры и эффекты в каждой секции.

Полный план работ — в [`plans/`](./plans/README.md). Начинать чтение оттуда.

## Стек

- Next.js 16 (App Router) + React 19, TypeScript strict
- CSS Modules + CSS-переменные, без CSS-фреймворка
- React Three Fiber 9 + three (появится на этапе 2)

## Команды

```bash
npm run dev     # дев-сервер
npm run build   # продакшен-сборка
npm run lint    # eslint
npx tsc --noEmit
```

## Структура

```
app/            роуты, метаданные, sitemap/robots
src/content/    единственный источник данных: профиль, проекты, i18n, режиссура 3D
src/ui/         DOM-компоненты: HUD, тема, SEO
src/lib/        утилиты
plans/          план реализации, 10 документов
```

Ключевое правило: `src/content` не знает про three, `src/ui` не знает про Next-роутинг.
Весь контент присутствует в SSR-разметке — сайт полностью читаем без JavaScript.
