# MATTER — план 3D-портфолио Михаила Пшеничного

Живой WebGL-сайт на React Three Fiber: один непрерывный 3D-мир, кастомный скролл,
переходы между страницами через порталы, шейдеры и эффекты в каждой секции.
Одинаково хорошо работает на десктопе и на телефоне.

## TL;DR концепции

Сайт — это **машина, которая материализует интерфейсы**. Сквозь весь сайт течёт
поток частиц («филамент»), который по мере скролла сгущается в объекты проектов:
зуб (Simplex Clinic) → футболка и кепка (Silkworm) → 3D-принтер (3D Outlet) →
чат-пузырь → канбан-доска. Метафора прямо отражает работу автора: «беру сырьё —
получаю готовый интерфейс», и цепляется за текущий коммерческий проект
(интернет-магазин 3D-принтеров).

Пять вещей, которые встречаются редко и делают проект запоминающимся:

1. **GPGPU-морфинг частиц** между облаками точек, сэмплированными из реальных GLB
   проектов. Один и тот же миллион частиц — все объекты сайта.
2. **Порталы вместо страниц**: карточка проекта — окно в отдельный мир
   (`MeshPortalMaterial`), клик раскрывает портал на весь экран, и это же является
   переходом на роут `/work/[id]`. 3D-сцена при этом ни разу не размонтируется.
3. **Тема меняет не CSS, а свет**: переключатель темы плавно интерполирует HDRI,
   tone mapping, экспозицию и параметры материалов в самой 3D-сцене.
4. **Физика скиллов с гироскопом на мобилке**: 20 технологий из резюме лежат в
   стеклянном сосуде на Rapier; телефон наклоняешь — они пересыпаются.
5. **Приватный проект как приём, а не как дыра**: 3D Outlet под NDA показан
   «зашифрованной» сценой — геометрия есть, но она глитчится и пикселизируется,
   NDA обыгран визуально.

## Ключевые решения, зафиксированные в плане

- **Next.js 16 App Router + React 19.2** — SSR для текста и SEO, View Transitions
  для DOM, серверные компоненты для контента. R3F требует React, поэтому Nuxt
  здесь не подходит, хотя основной коммерческий стек автора — Nuxt.
- **Один `<Canvas>` на всё приложение** в корневом layout, сцены раскладываются
  через `drei/View` и `tunnel-rat`. Переход между роутами не пересоздаёт WebGL-контекст.
- **Lenis как единственный источник времени**: прогресс и скорость скролла живут в
  zustand-сторе и попадают в юниформы шейдеров.
- **Четыре тира качества** (`ultra / high / medium / flat`) с автопонижением по
  реальному FPS. `flat` — полностью рабочий сайт без WebGL.
- **Двуязычность ru/en** — у автора есть опыт с i18next, это одновременно и фича
  портфолио, и требование рынка.

   `silkworm.glb`, `printer-scanner.glb` (в старом портфолио они уже были).
2. Скриншоты живых проектов в высоком разрешении для «витрин».
3. Решение по 3D Outlet: что именно можно показывать публично.
4. Реальные цифры для метрик (Lighthouse, размеры каталога, сроки) — сейчас в
   данных стоит расплывчатое «Optimized», это слабое место резюме.
